# Развёртывание на Vercel

Проект `zhanagasyr-ielts` в команде `zhana-gasyr` связан с `ureshisonaa/zhanagasyr_ielts`. Другие проекты не изменяются.

## Подготовлено

- Native Django / Python 3.12, WSGI `config/wsgi.py`, проверка конфигурации при сборке.
- Production-настройки и секрет Django сохранены в переменных Vercel.
- Создано приватное Vercel Blob хранилище `zhanagasyr-ielts-media`, подключённое к проекту. Запись, чтение и удаление проверены через официальный Python SDK.
- `PrivateBlobStorage` включается при наличии `BLOB_READ_WRITE_TOKEN`. Выдача медиа проходит существующие проверки доступа приложения.
- Аудио проверяется PyAV с встроенными библиотеками FFmpeg, системный ffprobe для проверки загрузок не требуется.
- PostgreSQL использует TLS; в Vercel отключены долгоживущие соединения и серверные курсоры. Без DATABASE_URL приложение намеренно не запускается на эфемерной SQLite.
- После изменений проходят 39 тестов.

## Production

Публичный адрес: https://zhanagasyr-ielts-zhana-gasyr.vercel.app

Neon подключён владельцем и связан с проектом; миграции выполнены при первой сборке. Начальные аккаунты `admin` и `student` созданы через защищённые одноразовые переменные, паролей в Git нет. Production-сборка получила статус READY; health и страница входа отвечают HTTP 200. Автодеплой из main включён.

`scripts/vercel-build.py` применяет миграции перед публикацией. Повторная сборка не меняет пароли существующих аккаунтов.

## Ограничения текущего запуска

- Vercel ограничивает тело запроса 4.5 МБ; для текущих форм используйте файлы до 4 МБ. Прямая загрузка больших аудиофайлов ещё не реализована.
- Проверка дедлайнов выполняется при обращениях к приложению и сохраняет исходное время окончания. Постоянный процесс expire_attempts на Vercel не запускается.
- SMTP не подключён. Администратор может выдавать ссылки приглашения/сброса через интерфейс.
- Production-база не содержит вымышленных демонстрационных результатов и экзаменов. Экзамены создаются администратором.
