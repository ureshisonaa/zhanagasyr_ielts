# Развёртывание на Vercel

Проект `zhanagasyr-ielts` в команде `zhana-gasyr` связан с `ureshisonaa/zhanagasyr_ielts`. Другие проекты не изменяются.

## Подготовлено

- Native Django / Python 3.12, WSGI `config/wsgi.py`, проверка конфигурации при сборке.
- Production-настройки и секрет Django сохранены в переменных Vercel.
- Создано приватное Vercel Blob хранилище `zhanagasyr-ielts-media`, подключённое к проекту. Запись, чтение и удаление проверены через официальный Python SDK.
- `PrivateBlobStorage` включается при наличии `BLOB_READ_WRITE_TOKEN`. Выдача медиа проходит существующие проверки доступа приложения.
- Аудио проверяется PyAV с встроенными библиотеками FFmpeg, системный ffprobe для проверки загрузок не требуется.
- PostgreSQL использует TLS; в Vercel отключены долгоживущие соединения и серверные курсоры. Без DATABASE_URL приложение намеренно не запускается на эфемерной SQLite.
- После изменений проходят 39 тестов.

## Блокирующий шаг

API автоматического подключения Neon вернул HTTP 422 `kind=install`. Владелец должен установить интеграцию и принять условия на странице:

https://vercel.com/zhana-gasyr/~/integrations/checkout/neon?productSlug=neon

Выбрать бесплатный тариф, регион Frankfurt и подключить к `zhanagasyr-ielts`. Официальный CLI направляет агентов в браузер для принятия условий владельцем. Интеграция пока не установлена, production-база и аккаунты не созданы.

## Завершение после подключения

1. Проверить DATABASE_URL проекта, применить миграции к внешней базе.
2. Создать администратора и ученика с отдельными случайными паролями. Не переносить локальную демобазу с историей.
3. Реализовать загрузку больших медиа частями или напрямую: Vercel ограничивает тело запроса 4.5 МБ, а прикладной лимит составляет 25 МБ. Малые загрузки проходят существующий endpoint.
4. Настроить периодический запуск expire_attempts при необходимости. Проверка дедлайнов при запросах уже работает и не продлевает время экзамена.
5. Включить `git.deploymentEnabled`, развернуть и проверить сборку, доступ по HTTPS, вход обеих ролей и сохранение данных.

**Публичный запуск ещё не выполнен.** Нельзя выдавать предполагаемый адрес или локальные демопароли как production-доступы. Автодеплой временно отключён до готовности базы и проверки ограничений загрузки.
