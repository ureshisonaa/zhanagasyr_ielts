# Vercel: состояние подключения

Создан отдельный проект `zhanagasyr-ielts` в команде `zhana-gasyr`, связанный с `ureshisonaa/zhanagasyr_ielts`. Существующий сайт `zhanagasyr.vercel.app` относится к другому репозиторию и не изменяется.

**Работающее IELTS-приложение на Vercel пока не опубликовано.** Автодеплой временно отключён через `git.deploymentEnabled=false`, чтобы push не публиковал неподготовленное приложение. Это не production-конфигурация Vercel.

Для полноценного запуска нужны:

1. Постоянный PostgreSQL (например, Supabase или Neon). SQLite на локальном диске Vercel использовать нельзя.
2. Приватное объектное хранилище аудио и изображений (например, Supabase Storage или S3). Текущая реализация с локальным MEDIA_ROOT предназначена для обычного сервера, не serverless.
3. Адаптер Python/WSGI для Vercel, безопасные production-переменные и миграции внешней БД.
4. Проверка аудио, доступная в runtime Vercel; текущий `ffprobe` присутствует в Docker/облачной среде, но не гарантирован в serverless runtime.
5. Прямая авторизованная загрузка больших файлов в хранилище: лимит тела запроса Vercel ниже текущего прикладного лимита 25 МБ.
6. Замена непрерывного `expire_attempts --loop` внешним планировщиком; проверка сроков при запросах уже реализована.
7. Создание отдельных production-аккаунтов администратора и ученика и проверка входа по реальному HTTPS-адресу.

Не переносите демобазу и `var/demo-credentials.json` в публичную сборку. Ключи Vercel, БД и Storage хранятся только в защищённой конфигурации. Ссылку и production-доступы можно выдавать после успешного развёртывания и проверки входа.
