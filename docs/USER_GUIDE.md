# Руководство ZhanaGasyr

## Администратор

1. Откройте «Пользователи → Добавить пользователя». Заполните имя, логин, email и роль. Передайте персональную ссылку пользователю по доверенному каналу; она действует 24 часа. Стандартного пароля нет.
2. При необходимости создайте группу, выберите преподавателя и учеников. Для множественного выбора используйте Ctrl/⌘.
3. В «Банк экзаменов → Создать экзамен» укажите название и источник материалов. Откройте настройки каждой секции: длительность в секундах, инструкции, текст.
4. Загрузите аудио/изображения в блоке материалов. Затем выберите аудио в Listening, изображение — в конкретном задании. Аудио проверяется `ffprobe`, изображения — Pillow.
5. Добавьте вопросы. Поддерживаются короткий ответ, один/несколько вариантов, сопоставление, True/False/Not Given, Yes/No/Not Given. Составные задания разбиваются на отдельные вопросы. Для текстового ответа допустимые варианты перечисляются по одному на строку; для multiple select все ключи образуют единственный правильный набор.
6. Каждый вопрос Listening/Reading даёт один raw-балл. Настройте таблицу порогов именно для этой версии: `[[0,0],[1,3],[2,5],[3,7],[4,9]]` — **только демонстрационный пример для четырёх вопросов**, не официальная шкала IELTS. Для реального теста нужна согласованная калибровка.
7. Writing должен иметь ровно два задания, Speaking — три. Опубликуйте версию. Проверки не дадут опубликовать неполные секции, некорректные ключи, шкалы или Listening без аудио.
8. «Назначения → Назначить экзамен»: выберите ученика **или** группу, опубликованную версию, проверяющего, даты и число попыток. Время отображается по `Asia/Qyzylorda`. Повторное назначение той же версии тому же ученику не создаёт дубликат.
9. После проверки преподавателем откройте результат и нажмите «Опубликовать». До публикации ученик не видит баллы и комментарии.
10. Опубликованный тест не редактируется. «Новая версия» копирует вопросы и материалы; старые назначения сохраняют свою версию. Архивирование скрывает экзамен из выбора новых назначений, не отменяя старых.

Блокировка пользователя отзывает текущие сеансы и сохраняет историю. Восстановление доступа не восстанавливает старые сеансы. Новую ссылку входа можно выдать со страницы пользователя. Для смены собственного пароля используется «Мой профиль».

При технической неисправности администратор может аннулировать неопубликованную попытку с обязательной причиной и выдать одну дополнительную. Время назначения не продлевается, история сохраняется. Для нового срока создайте назначение новой версии.

## Преподаватель

1. «Проверка работ» содержит только назначенные вам попытки.
2. Откройте Writing: доступны оба текста ученика. Выставьте четыре критерия для каждого задания. Task 2 имеет двойной вес.
3. В Speaking прослушайте три записи; заполните Fluency and Coherence, Lexical Resource, Grammatical Range and Accuracy, Pronunciation.
4. Заполните комментарий. «Сохранить черновик» сохраняет работу без итогового балла; «Завершить проверку» фиксирует секцию для последующей публикации.
5. После обеих проверок формируется Overall. Публикует администратор. Преподаватель не может изменять уже опубликованную оценку.

В черновике также требуется заполнить все четыре критерия (можно предварительно). Если уйти со страницы с несохранёнными правками, браузер предупредит. Автоматической публикации и ИИ-проверки нет.

## Ученик

1. Получите ссылку от администратора и установите пароль. Войдите по email или логину.
2. Откройте «Мои экзамены». На странице инструкций проверьте звук и микрофон, прочитайте правила и подтвердите готовность.
3. Секции идут последовательно. Время продолжает идти при перезагрузке, выходе из аккаунта, закрытии браузера и потере сети. Отправка сразу запускает следующую секцию; вернуться назад нельзя.
4. Следите за надписью «Сохранено на сервере». Неподтверждённые текстовые ответы сохраняются локально. При конфликте вкладок сначала скачайте локальную копию, затем обновите страницу.
5. В Listening запуск по умолчанию однократный. Не обновляйте страницу во время воспроизведения. При неисправности обратитесь к администратору.
6. В Speaking запишите каждую часть и нажмите «Остановить». Дождитесь надписи «Запись сохранена на сервере». При неудачной отправке доступны повтор и скачивание файла. Неотправленная остановленная запись сохраняется в IndexedDB. Незавершённая запись микрофона при аварийном закрытии вкладки может потеряться.
7. Минутный таймер Part 2 — помощь для подготовки; он не останавливает общее время Speaking.
8. После экзамена дождитесь публикации. Результаты и обратная связь появятся в истории.

Используйте личное устройство или выходите из аккаунта на общем компьютере. Выход через кнопку очищает локальные черновики приложения; не выходите, пока важные изменения не подтверждены сервером. При полном исчезновении интернета после окончания времени поздние ответы не принимаются — локальная копия нужна только для разбора с администратором.

## Разрешения

| Действие | Super Admin | Admin | Teacher | Student |
|---|---|---|---|---|
| Администраторы и роли персонала | Да | Только ученики/преподаватели | Нет | Нет |
| Тесты/назначения/группы | Да | Да | Только просмотр своих групп | Нет |
| Проверка | Все работы | Все работы | Только назначенные | Нет |
| Публикация | Да | Да | Нет | Нет |
| Исправление опубликованной оценки | Да | Отдельное разрешение | Нет | Нет |
| Аудит/CSV | Да | Отдельные разрешения | Нет | Нет |
| Просмотр результатов | Все | Все | Назначенные | Свои опубликованные |

## Конфиденциальность перед запуском

Учебный центр должен утвердить сроки хранения ответов/аудио, порядок удаления, правила работы с несовершеннолетними и необходимые согласия. В приложении есть уведомление о записи, но оно не заменяет согласованную юридическую процедуру. Не включайте настоящие данные в демобазу.
